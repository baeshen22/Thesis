## Opportunities to improve visual explanation

1. One consistent 3D model for every view. The source images depict at least three different arenas and two museums.
2. Masterplan as a clean, labelled render with editable PowerPoint callouts. The source plan carries baked-in, partly illegible text.
3. No real brand logos. Brand zones are left blank so the deck does not imply tenant commitments to a public authority.
4. Daylight views for spatial understanding, with dusk views kept to two.
5. A clear split between commercial, visitor-attraction and operational zones.
6. Site options presented as source material, separated from the concept.
